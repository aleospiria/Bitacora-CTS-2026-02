# Bitácora CTS: incendios forestales en Colombia

Sitio web con la bitácora interactiva del proyecto de Ciencia, Tecnología y Sociedad (2026-02).
Hecho con React y Vite. Diseño pensado primero para celular y adaptado a escritorio.

## Desarrollo

Instalar dependencias con `npm install` y levantar el servidor local con el script `dev`.

## Contenido

Todo el texto de la bitácora está en `src/data.js`. Los campos marcados como pendientes
aparecen en el sitio como cajas "Por completar".

## Despliegue

El proyecto se despliega en Vercel desde GitHub. Configuración: framework Vite,
comando de build `npm run build`, carpeta de salida `dist`.
